# Protected App Routes

Staff-only App Router surfaces — **24 top-level route folders, 44 pages**. The module
tables in `CLAUDE.md` and `docs/maps/module-map.md` list them; `docs/maps/legacy-routes.md`
covers the redirect aliases (`collections`, `dues`, `advanced`, `setup`, `fee-structure`).

`session/` holds only `actions.ts` — there is no page there. Session switching happens
through the pill in the workspace shell.

- Canonical admin tools route: `/protected/admin-tools`
- Legacy route `/protected/advanced` is preserved as redirect compatibility.
